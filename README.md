# A-beginner-cyber-security-project-documenting-an-internal-security-audit-for-a-fictional-company.

Eve's Haven: Internal Security Audit

Project Overview

This project documents an internal security audit and risk assessment of Eve's Haven a fictional company. The purpose was to assess existing security controls, identify weaknesses, and understand the potential risks to the organisation.

Audit Scope

The assessment covered:

- IT assets and employee devices
- Internal networks and business systems
- Customer information and data storage
- Security controls and regulatory compliance
- Physical security and warehouse assets

Key Findings

During the assessment, I identified several security weaknesses:

- No multifactor authentication (MFA).
- Excessive employee access to sensitive customer information.
- Customer credit information was not encrypted.
- No intrusion detection system (IDS).
- No disaster recovery plan.
- No backups for sensitive data.
- Password requirements did not meet the specified complexity requirements.
- No regular maintenance schedule for legacy systems.

Existing Security Controls

The report also identified controls already in place, including:

- A firewall with defined security rules.
- Regularly monitored antivirus software.
- Physical security measures, including locks and CCTV.
- Privacy policies and procedures.
- A process for breach notifications to EU customers.

Skills Practised

- Security control assessment
- Asset identification
- Risk identification
- Access control concepts
- Security audit documentation
- Basic risk assessment

Lessons Learned

This project helped me understand how security weaknesses can affect an organisation's data, systems, and business continuity. It also improved my understanding of access control, data protection, security monitoring, and disaster recovery.

Project Limitations

Eve's Haven is a fictional company. This was a learning exercise based on a security assessment scenario, not an audit of a real organisation.
